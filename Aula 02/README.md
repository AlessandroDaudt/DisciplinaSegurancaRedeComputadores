# Aula 02 — Atividades práticas em PowerShell

Esta aula reúne os laboratórios práticos da disciplina. Cada atividade tem uma interface própria para o aluno selecionar os arquivos, seguir um roteiro curto e executar o exercício sem precisar usar comandos.

## Como usar

1. Escolha a atividade na tabela abaixo.
2. Abra a interface correspondente no PowerShell ISE ou no Windows PowerShell 5.1.
3. Mantenha os arquivos de exemplo ou use o botão Selecionar para escolher seus próprios dados de laboratório.
4. Clique no botão verde para executar e leia o resultado na própria tela.

Não há uma interface geral. Isso mantém cada tela pequena, focada em um único conceito e mais fácil de usar em sala de aula.

## O que cada tela oferece

- Objetivo e instruções curtas.
- Seleção de arquivo ou pasta quando a atividade usa dados de entrada.
- Botão Abrir roteiro para consultar a explicação completa.
- Botão Abrir pasta para localizar dados e relatórios.
- Resultado visível na própria tela.

## Segurança e saídas

Os dados fornecidos são sintéticos. As atividades trabalham localmente e os arquivos gerados ficam em pastas resultado. A atividade 05 pode criar um certificado autoassinado no perfil do usuário; a atividade 09 oferece uma coleta local opcional somente de leitura.
