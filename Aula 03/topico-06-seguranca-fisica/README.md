# Tópico 06 — Segurança Física

As cinco práticas deste tópico foram pensadas para execução rápida em sala de aula. Cada uma possui uma tela própria, um arquivo de exemplo, um roteiro curto e uma área de resultado visual.

## Atividades

| Atividade | O aluno pratica | Dados de exemplo |
| --- | --- | --- |
| 10 — Auditoria de acessos físicos | Identificação de acessos conformes, de atenção e críticos. | acessos-fisicos.csv |
| 11 — Matriz de controles físicos | Escolha de controles para reduzir riscos de cenários diferentes. | cenarios-controles-fisicos.csv |
| 12 — Avaliação do ambiente do CPD | Leitura de lacunas em perímetro, acesso, incêndio, energia e climatização. | ambientes-cpd.csv |
| 13 — Auditoria de mídias | Verificação de armazenamento, transporte e exposição ambiental. | inventario-midias.csv |
| 14 — Rotina segura do CPD | Tomada de decisão diante de situações operacionais. | cenarios-rotina-cpd.csv |

## Fluxo das telas

1. Selecionar o arquivo de exemplo.
2. Escolher o cenário quando a atividade apresentar opções.
3. Executar a análise ou validar a decisão.
4. Ler o resultado e abrir o roteiro quando necessário.

Os relatórios são gravados automaticamente na pasta resultado após cada execução. Os dados de entrada não são alterados.

## Segurança

Os cenários são exclusivamente didáticos. Não utilize estes scripts para operar, testar ou alterar dispositivos, controles de acesso ou infraestruturas reais.
